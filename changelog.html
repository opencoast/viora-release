1.10.1

2026-10-24 Latest

Fix release: video frames and safer agent renames.

Added

  • Frames for a Videos folder. Folder info has a Frames setting (Auto, Fewer, Standard, More) that decides how many frames are taken from each video. Subfolders inherit it.
  • Take frames again. Next to Frames, it takes a folder's videos apart again and moves them to the front of recognition. If recognition is not running, it tells you.
  • Scenes in the preview strip. Shots that recognition found and the strip missed are added to the video viewer's strip with a mark, so you can jump straight to them.
  • For agents: rename up to 200 items as one change that a single Undo takes back, page through a folder's subfolders, and list the changes agents have made.

Changed

  • How many frames a video gets. The count now grows with the square root of the video's length, instead of one frame every 30 seconds capped at 24. On Standard, a one-minute clip gets about 4 frames, ten minutes 13, an hour 31 and two hours 44. Short clips repeat themselves less, and long films no longer end up with one frame every five minutes.
  • A cleaner preview strip. It skips blank moments and shows each shot once, up to 12 frames.
  • Server logs name the library. Every line about recognition, jobs, events, agent tools and covers says which library it is about.

Fixed

  • An agent could rename a file without its extension. The file then dropped out of the library along with its tags, and Undo could not find it. A new name must now keep the extension; only its case may change.
  • A folder renamed or created with a name the scanner skips (such as @eaDir, #recycle or $RECYCLE.BIN) disappeared from the library with everything inside it. Those names are now refused.
  • A novel renamed to something like readme.txt, or kept next to a picture with the same name, no longer leaves the library.
  • When an agent's rename, move, delete, undo or restore skips an item, it now explains which rule the item broke, instead of just saying "invalid".

Before you upgrade

  • A 1.10.1 app still connects to a 1.10.0 server. Frames and scene marks need a 1.10.1 server, so rebuild the NAS image to get them.
  • If you use recognition, it goes over the videos whose frame count changed under the new rule. A library with many videos stays busy for a while after the upgrade.
  • Preview strips made before 1.10.1 add scenes less precisely. Use Take frames again on a folder to redo them.

1.10.0

2026-10-18

Your phone, your own agent over MCP, and the Plugins Store.

Added

  • On your phone. The server serves a read-only page: pick a library, unlock it, browse folders and search, with viewers for photos, video, comics and novels (txt, md, epub, pdf). Add it to the home screen; over https it opens offline.
  • Let a phone into a local library. "Open in a browser · Let a phone in" on the library card. It is off by default, and turning it on requires a password.
  • Your own agent, over MCP. Each library can hand an agent you already use a set of tools: overview, folder summaries, search, item details, and looking at pictures, video frames, comic pages and novel text. If you allow it, the agent can also create folders, rename, move, send to Trash and undo. It is off by default and uses a key per library. The AI switch in the sidebar opens the setup guide.
  • Agent notes. A third switch lets an agent write down what it saw as a note on an item, with moments for video. Only agent search reads them. Viewers show them as Agent notes, marked as written by an agent.
  • Plugins → Store. Install plugins and model packs from the official catalog, through a proxy if you set one.
  • Rename in Gather. Replace text, add a prefix or a suffix, and see every old name → new name before anything changes. Collisions and names the server would refuse are held back with the reason. One Undo takes the whole batch back.
  • Video conversion you can follow. Progress and time left, cancel and start again, and it keeps going when you leave the viewer. Playback starts as soon as the first part is ready. Large videos use the Mac's hardware encoder and fall back to software if it fails.
  • Convert and play for a .mov or .mp4 the player refuses, with the reason the server could not read it. When a video cannot play, the viewer keeps its path, size and Download in view.
  • Thirty days of Activity. Every change from the last 30 days (it used to be the last 20), filtered by time or by who made it, grouped by day. Undone changes stay in the list, marked Undone.
  • Files. Show in Finder or Explorer; a Recently opened row at the top of My Library (this computer only); remove a Root from a local library; point a NAS Root at a folder mounted on this machine; Trash pages through its items and deletes one for good.
  • Saving. Download on a photo saves a full-resolution JPEG without embedded metadata, with the original in the ▾ menu. The comic reader can save the current page.
  • Search finds recognition's tags and people, not only file names.
  • Video cards play their preview frames when you hover over them.
  • Update check. The library picker checks once a day for a new version. A copy that is not an official build is marked Unofficial.

Changed

  • A search started in a folder stays in that folder and below, with a way to widen it to the whole library. Results follow the wall's sort, and the "Date" sort is now called "File date".
  • Gather is a selection mode: click or drag to pick, up to 300 items. It refuses the extra items instead of quietly pushing out older ones, and Clear asks first.
  • My Library, Tags, People and Favorites share one right-click menu, one multi-select and one selection bar.
  • Walls update in place as files come and go: cards slide to their new spot instead of the wall flashing empty.
  • Activity names the full destination folder of a move (Moved 3 items to Media/Photos/2025).
  • On a wall, arrow keys move along the grid. Every dialog closes with both × and Esc, and confirmations use Viora's own dialogs.
  • Merging people and "Not this person" ask first, and a face taken out can be put back while the panel is open. A name in the player's info bar opens that person's wall.
  • With the sidebar collapsed, the library icon opens the folder drawer. Saved NAS connections can be renamed and given a new address.
  • Video from a NAS plays more smoothly: the server reads ahead in larger pieces instead of reopening the file several times a second. Videos in one library share a single volume setting.
  • Plugins is arranged by what each plugin does.

Fixed

  • A wall refreshing in the background no longer restarts the video you are watching.
  • A video still converting plays at the library's volume and mute instead of full volume.
  • A search inside a folder stays in that folder while files change elsewhere in the library (a scan, a move, an agent).
  • A search that found folders but no files no longer says the library is empty.
  • The sidebar and the wall follow files moved between folders, including moves made by an agent or by Undo.
  • A download landing in the folder you are reading no longer makes the reader flicker.
  • On macOS, changing only the case of a name (IMG → img) is no longer treated as a collision.
  • On the phone page: a broken comic page is no longer fetched over and over; the page lines up after rotating; back returns to where you were; nothing sits under the Home indicator.

Removed

  • The sidebar AI (Beta). Its saved endpoint, encrypted API key and chats are deleted the first time 1.10 starts. Connect your own agent over MCP instead.

Before you upgrade

  • Update the app and the server together. A 1.10 app will not connect to a 1.0 server, so rebuild the NAS image as well.
  • Once a library has been opened by 1.10, do not go back to a 1.0 server.
  • The phone page needs https to open offline. Over http it works, but it caches nothing and its traffic is not encrypted.
  • On iPhone, remove an icon you already added to the home screen and add it again.
  • Known issue: in iPhone home-screen mode, the strip at the top takes the system status bar's colour instead of the page's (an iOS 26 issue).

1.0.0

2026-09-28

First release.

The first public version of Viora: a desktop library for the folders you already keep, on this computer or on a NAS.

Added

  • One wall for everything. Photos, video, comics and novels in one scroll, indexed in place. Nothing is imported or copied.
  • A room for each kind of file: a photo and video viewer, a comic reader and a novel reader. Folders can be typed as Images, Videos, Comics or Novels.
  • This computer or a NAS. The app starts its own local server, or connects to the same server running in Docker, with several libraries if you want them.
  • Tags, people and favorites, each with its own wall. Recognition runs only after you install a model pack and allow it.
  • File management that keeps tags and details through renames and moves, with a Trash and Undo.
  • Source plugins that add details from outside sites, installed only when you choose to.

Every installer, including older builds, is on GitHub Releases. Within one version, a newer build number repackages the same release.

A personal media library for photos, video, comics and novels.
